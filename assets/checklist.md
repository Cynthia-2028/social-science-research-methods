# 投稿前研究设计自查 40 项

> 用法：逐项打勾。**打不了勾的，就是审稿人会问的那一条。**
> 标记说明：★ = 致命项（不过则结论不能成立）；☆ = 重要项（削弱但可补）；其余为规范项。

---

## 一、问题与设计（6 项）

- [ ] ★ 我的问句能用一句话说出，且含一个明确的动词
- [ ] ★ 我的结论级别（描述/关联/因果/机制/概念/预测）已明确写出
- [ ] ★ 我的设计与结论级别相称（没有用横断面谈过程、用便利样本推总体）
- [ ] ☆ 我能说出"若结论成立，它推翻什么"
- [ ] ☆ 我已说明现有解释在什么情形下不成立（而非"没人研究过"）
- [ ] 我的摘要与方法节的动词一致（摘要写"影响"、方法写"相关"，会被抓）

## 二、概念与测量（8 项）

- [ ] ★ 核心概念的维度已列出（3–7 个），每个维度有边界说明
- [ ] ★ 每个维度至少有一个指标，没有"只定义没测量"的维度
- [ ] ☆ 有概念—维度—变量—题目四列表，且没有空行
- [ ] ☆ 已报告至少一项效度证据（内容/效标/构念）
- [ ] ☆ 已报告信度（重测、内部一致性或编码者间一致性）
- [ ] ☆ 跨群体或跨时点比较时做过等值性检验
- [ ] 已说明每个变量的测量层次，且统计处理与层次匹配
- [ ] 已做"换一种合理操作化"的稳健性检验

## 三、数据与抽样（8 项）

- [ ] ★ 目标总体已按单位/时间/空间/纳排四维界定
- [ ] ★ 已说明抽样框是什么，并估计了覆盖率
- [ ] ★ 已说明"谁不在框里"，以及这对结论的影响
- [ ] ☆ 已报告应答率，且写明分母定义与资格比例 e 的估计
- [ ] ☆ 已比较应答者与未应答者在关键变量上的差异
- [ ] ☆ 若为聚类/多阶段样本，已报告设计效应或使用聚类标准误
- [ ] 已说明加权方案（四个来源），并报告权重变异系数
- [ ] 已确认结论主语与数据的观察单位同层

## 四、识别与分析（10 项）

- [ ] ★ 三条识别假设（一致性/可交换性/正定性）已逐条写出
- [ ] ★ 可交换性的论证有实质依据（制度规则、分配机制、前处理平衡），不是"我控制了变量"
- [ ] ★ 已明确估计目标是总效应还是直接效应
- [ ] ★ 控制变量已按五类（混杂/中介/对撞/工具/精度）分类，并说明进出理由
- [ ] ☆ 已报告基线平衡表（实验或匹配）
- [ ] ☆ 已报告系数随控制集逐步加入的变化轨迹
- [ ] ☆ 已声明"控制变量系数不作实质解释"
- [ ] ☆ 函数形式有依据（分箱均值图 / 残差图），不是默认线性
- [ ] 共线性已诊断（VIF 或相关矩阵），并说明处理方式
- [ ] 影响力点已识别，并做了含/不含的敏感性分析

## 五、推断与不确定性（6 项）

- [ ] ★ 每个关键结论都报了效应量与置信区间，不只报 p 值
- [ ] ★ 结论措辞与证据级别匹配（相关不写"导致"）
- [ ] ☆ 已说明可检测的最小效应（或功效分析）
- [ ] ☆ 多重比较已处理（校正或标记为探索性）
- [ ] ☆ 已排除"停在显著处"（报告了完整模型序列与停止规则）
- [ ] 若用预测指标，已报选定阈值下的混淆矩阵并与无信息基线比较

## 六、边界与伦理（6 项）

- [ ] ★ 已写明结论适用的人群、时期与制度环境
- [ ] ★ 已写明"不能支持什么推断"
- [ ] ☆ 已指出最脆弱的假设及其可能的失效情形
- [ ] ☆ 已讨论未测混杂的可能方向与量级
- [ ] 知情同意与匿名/保密层级已交代（尤其在线数据）
- [ ] 数据与脚本的可得性已说明（含随机种子与切分方式）

## 七、报告规范（6 项）

- [ ] 软件与版本已写
- [ ] 每个变量的操作化定义与量纲已写
- [ ] 缺失比例与处理方式已写
- [ ] 系数标明是标准化还是未标准化，分类变量标明参照组
- [ ] 表格含 N、R²（或对应拟合指标）、标准误，表注写明量纲
- [ ] 报告数字内部一致（区间含点估计；含 0 ⇔ p>0.05；百分比合计 100）

---

## 交稿前最后三问

1. **哪一个打不了勾的项最可能让结论撤回？** 先补它。
2. **审稿人第一句会问什么？** 通常是第三节（数据能代表谁）或第四节（凭什么说因果）。
3. **我的局限段是套话还是真话？** 套话会被识破，且浪费了一次展示"我知道边界在哪"的机会。
