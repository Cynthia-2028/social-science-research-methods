# 04 · 抽样、无应答与概化

**一句话结论：描述的可信度取决于"谁不在样本里"，而不是"样本有多大"。**

---

## 1. 总体不是"一群人"，而是一句界定

总体必须同时界定四个维度，缺一个就无法判断抽样对错：

- **单位**：个人、家庭、组织、事件、帖子？
- **时间**：哪一年、哪几个月？
- **空间**：全国、某省、某几个城市、某平台？
- **纳入与排除**：机构内人口算不算？在校生算不算？非户籍常住算不算？

**抽样框**是把这个抽象界定变成可操作名单的尝试。框与总体之间的落差就是**覆盖误差**——它在抽样之前就存在，用同一个框做普查也照样存在。

**核对清单（逐项问）**
1. 谁不可能出现在名单上（无电话、无户籍、无固定住所、机构内人口、未成年人、流动人口）；
2. 谁被重复列入（多套住房、多个手机号、跨平台账号）；
3. 名单多久更新一次；
4. 名单是否因行政要求而系统性漏掉某类人；
5. 框里有没有"外来单位"（非目标人群）。

**硬判据：在方法章报告"框的覆盖率估计"与"框外人口的特征"，而不是只报样本量。** 一个覆盖不全的百万级样本，可能不如一个覆盖完整的五万级样本。

---

## 2. 覆盖误差：两个因子相乘，缺一不可

```
覆盖偏误 ≈ 未覆盖率 × (覆盖者均值 − 未覆盖者均值)
```

两个推论：
1. **覆盖误差在抽样之前就存在**，换抽样方法不能修复；
2. **未覆盖率小不等于偏误小**——只要覆盖者与未覆盖者在目标变量上差异够大，偏误依然可观。反之，未覆盖者若与覆盖者在目标变量上无差异，覆盖误差就不构成偏误。

**对策（成本由低到高）**
1. 外部总量校准（用普查或行政记录对齐边际分布）；
2. 框内补充更新（半开区间法：以上门时相邻门牌号为界，把区间内新建或漏列单位补入并给同一入样概率）；
3. 多重抽样（按网络规模取 1/k 权重）；
4. 双框设计（主框 + 补充框，重叠部分用多重框估计量）。

**判据：必须同时估"覆盖率"与"覆盖者—未覆盖者差异"，只报覆盖率属无效论证。**

## 3. 概率抽样：五种形制与各自代价

| 方法 | 怎么做 | 优点 | 代价/风险 | 判据 |
|---|---|---|---|---|
| 简单随机 | 编号后抽随机数 | 统计理论最简单 | 大框难操作 | 有没有完整的元素名单 |
| 系统 | 按间距每隔若干取一个 | 操作简便 | 名单若周期性排列，会系统性抽到某类人 | 名单有没有隐含周期 |
| 分层 | 先分层，层内随机 | 保证层比例、通常降方差 | 需可靠分层信息；分层变量须与目标变量相关才划算 | 层信息可靠吗、与 y 相关吗 |
| 整群 | 先抽群（学校、社区、病区），群内调查 | 大幅降低成本 | 群内同质会增大设计效应 | 群内是否同质 |
| 多阶段 | 上述方法串联 | 兼顾成本与覆盖 | 误差估计复杂 | 是否声明了层与初级抽样单位 |

**设计效应（deff）**：复杂样本的方差与同规模简单随机样本方差之比。整群抽样几乎总是让它大于 1；分层得当可以小于 1。

**实例量级**：某三阶段抽样中，平均受教育年限的设计效应为 13.43，意味着 3000 人的样本，其真实标准误相当于 223 人的简单随机样本。**忽略设计效应的后果是置信区间过窄、显著性被系统性高估。**

**操作**：用调查估计命令声明层、初级抽样单位与权重，或用聚类稳健标准误。**不要给"±3%"这类只在简单随机抽样下成立的数字。**

## 4. 非概率抽样：五种用法与"能推到哪"的边界

| 方法 | 适用 | 结构性弱点 | 能支持什么 |
|---|---|---|---|
| 便利抽样 | 预试、极端受限场景 | 自选偏误，无法估计 | 只能提示方向，不能估计比例 |
| 判断抽样 | 总体难枚举但关键案例可见（运动领袖、偏差案例） | 选择标准由研究者定，不可复核 | 机制、类型、极端情形 |
| 滚雪球 | 隐蔽或难以接触人群 | 沿既有网络收缩，早期被引荐者过度代表 | 网络结构、可达人群特征 |
| 配额 | 先按比例建矩阵再填格 | 配额依据的框可能过时；格内选择仍有系统偏差 | 表面像概率抽样，实际不能算抽样误差 |
| 理论抽样 | 质性研究，按理论进展调整 | 依赖理论成熟度 | 概念与机制 |

**统一判据：先问"推断目标是参数还是机制"。**
- 要估计比例 → 非概率抽样不合格；
- 要发现机制、生成类型 → 可以，但必须写明"它不能支持何种概括"。

## 5. 样本量：影响精度，不修复代表性

三条硬规则：

1. **概率抽样的精度公式适用于较大样本**（通常至少一百个单位，常见是数千）。
2. **精度提升是递减的**：显著性水平固定时，**样本量翻四倍才能把置信区间减半**（区间宽度 ∝ 1/√n）。
3. **当总体远大于样本时，总体规模对精度影响很小**，起决定作用的是样本量本身。

**判据：如果有人用"我们调查了十万人"证明可靠，先问三句：框完整吗？应答率多少？加权了吗？** 框偏差大时，十万人只是把同样的偏差估计得更精确。

**功效视角的样本量**（因果与实验路线）：
- 四个量互相约束：显著性水平 α、功效 1−β、要检出的效应量 d、样本量 n。给定三个，第四个被确定。
- 近似式：每组 n ≈ (z_{1−α/2} + z_{1−β})² / d²。
- 量级：双侧、α=0.05、功效 80%、要检出 0.5 个标准差差异 → 每组约 64 人；若每组仅 25 人，最小可检出效应升到 0.81 个标准差。
- **含义：样本量由"你想检出多大的效应"反推，不是越多越好。**

**低功效的双重代价**：不只漏检真实效应，还会**系统放大已发表的效应量**（"侥幸显著"的估计往往偏大）。链条是：低功效 → 显著结果少 → 只有大估计过关 → 发表 → 文献效应量偏大 → 复制失败。

## 6. 总误差框架：把"准不准"落到具体环节

调查可以拆成两条链，每个箭头的错位就是一种误差：

```
左链（测量）：构念 ──▶ 测量 ──▶ 作答 ──▶ 编辑后数值
右链（抽样）：目标总体 ──▶ 抽样框 ──▶ 样本 ──▶ 应答者
```

| 落差 | 误差名称 | 对策 |
|---|---|---|
| 构念 → 测量 | 效度（构念效度、内容效度） | 维度—指标对应表、效度研究 |
| 测量 → 作答 | 测量误差（理解、回忆、社会赞许） | 题项设计、认知访谈、自填模式 |
| 作答 → 编辑值 | 加工误差（编码、编辑、录入） | 双编码、可执行编辑规则、保留改前值 |
| 总体 → 框 | 覆盖误差 | 多框、补充更新、外部校准 |
| 框 → 样本 | 抽样误差 | 概率抽样、分层、控制整群规模 |
| 样本 → 应答者 | 无应答误差 | 多次接触、激励、加权、敏感性分析 |
| 最后调整 | 调整误差 | 报告权重变异、做替代校准 |

**关键认识：误差是"单个统计量"的属性，不是"整份调查"的属性。** 同一份数据里，收入的误差可以很大而性别的误差接近零。这是"应答率高不等于质量高"的形式化根源。

**十二项诊断清单**（至少 8 项有书面证据才可称"质量可控"）：

1. 构念—题目对应表是否存在；
2. 框是否覆盖目标总体、是否含外来单位；
3. 每个框元素是否有已知非零入样概率；
4. 分层、整群是否有设计效应说明；
5. 计划样本量与实际完成量之差及其构成；
6. 接触率、拒访率、其他未完成率是否分列；
7. 应答者与未应答者在框变量上的差异是否估过；
8. 题干是否经认知测试或行为编码；
9. 访问员效应与记录方式是否被评估；
10. 编码与编辑规则能否被第二人复现；
11. 权重的变异系数、极值、截尾规则是否报告；
12. 加权后关键分布与外部总量是否吻合。

**缺第 2、7、11 项中任一项，描述性推断应降级为探索性。**

## 7. 无应答：率只是风险指示器

```
无应答偏误 ≈ 无应答率 × (应答者均值 − 未应答者均值)
```

**三条独立理由说明"应答率高 ≠ 质量高"**：
1. 公式上偏误是"率 × 差异"，率只是两个因子之一；
2. 把参与视为随机过程后，偏误取决于**目标变量 y 与应答倾向 p 的协方差**——所以同一调查内不同估计的无应答偏误可以差异极大；
3. 经验证据：出口民调各站点应答率从 10% 到 90% 分布，与估计误差无明显关系（因为拒访原因与党派差异无关）。

**判据：判断某估计是否受无应答威胁，看"应答倾向是否与 y 相关"，而不是看总应答率。**

**应答率怎么算**：分子是完成数，难点在分母——
- 框内含非目标单位，未应答者资格未知 → 须估计资格比例 e；
- 整群未应答时群内元素数未知；
- 入样概率不等，是否加权未定。

**模板写法**：
> 应答率 = 完成数 /（完成 + 拒访 + 未接触 + 其他合格 + e × 资格未知），e 由本轮估计为 0.xx。

无法估计 e 时，报告两个率（资格未知计入 / 不计入分母），真值必落在区间内。

**单位无应答 vs 项目无应答**：前者整行缺失（只留框变量），污染所有用到该个案的统计量；后者行内某格缺失，只污染涉及该题的统计量。成因也不同（前者基于对调查的简短介绍做决定，后者发生在题目完全暴露之后），**对策因此分岔**：前者用加权类调整，后者用插补。**两类分别报率，不合成一个"缺失率"。**

**降低无应答：按"接触 — 初始决定 — 最终决定"分段下药**

| 阶段 | 有效工具 | 注意 |
|---|---|---|
| 接触 | 增加尝试次数与时段（工作日晚间、周末白天）、延长调查期、控制访问员工作量 | 每次尝试都要记录结果 |
| 初始决定 | 主办方信誉（政府/大学优于商业机构）、预付费式小额现金激励（现金优于实物、先付优于后付、有递减回报）、访问员"因人调整"而非照本宣科 | 预告信若强调敏感内容反而压低应答 |
| 最终决定 | 换访问员、换模式、劝说信、两阶段设计 | 记录转换效果 |

**判据：每个工具都要问"它改变的是接触概率还是应答意愿"，二者影响的估计不同。**

## 8. 加权：把设计造成的比例还原，不是万能校正

**四个来源，相乘得最终权**
1. 一阶比率调整（用已知总量校正框）；
2. 不等概率调整（1/入样概率）；
3. 无应答调整（1/组内应答率）；
4. 事后分层（对齐外部边际）。

**无应答调整的关键假设**：组内缺失随机——组内应答者可视为全体样本的随机子集。**因此只能用"全样本已知"的变量（框变量），不能用只在应答者中收集的变量。**

**代价三条**
- 权重会放大方差，分布越不均越严重；
- 极值权重让个别个案主导估计；
- 子类分析（某省、某年龄组）的有效样本量骤降。

**判据：报告权重的变异系数与最大值/中位数比；变异系数大于 3 应截尾或合并权重类，并说明对结论的影响。** 同时给"加权估计"与"未加权 n"，让读者判断有效样本量。**反对"只在部分分析里用权重"**——两套口径会产生无法解释的不一致。

**事后分层的两个前提**：外部边际准确；校准变量与目标变量相关。类别越细方差膨胀越厉害，通常只用 2–4 个变量交叉。只满足前者是形式主义，只满足后者无法校准。

**调整误差提醒**：事后调整降偏误但增方差；外部总量有误时会**注入**新偏误。调整只改变权重，不创造信息。判断标准是"换一组校准变量重跑，结论是否翻转"。

## 9. 概化的两条逻辑（不能混用）

| | 统计概化 | 理论概化 |
|---|---|---|
| 依据 | 概率论 | 理论推理 |
| 样本量由 | 精度与置信度 | 理论饱和（新增单位不再提供既相关又新的信息） |
| 样本选择 | 随机 | 战略（按理论维度覆盖全范围、并能挑战初步假设） |
| 能支持 | 总体参数估计 | 机制、类型、条件性命题 |

**判据：若推断目标是参数，非概率抽样不合格；若目标是机制，随机性不是必需，但必须说明"为什么这个现场值得看"。**

**质性研究的目标不是"代表性"，而是"公平性"**：
- 所选现场不应系统性地把研究者引向过度自信的推断；
- 判据两条：该现场是否在关键维度上预先设定了结论方向；研究者能否说明"若换一个现场，哪些结论会变、哪些不会"。

**若总体内部同质**，任何现场都给出同样结果；**若总体异质**，代表性样本反而会把异质性平均掉，使你看不到机制。这是"单案例不能概化"的反驳要点。

**偏差案例何时有决定性力量**：只有当理论以**无条件形式**明确否定了某类案例的存在，且该理论若被反驳会陷入深层困难时，单个反例才有决定性；否则反例只是补充。

## 10. 层次错配：生态谬误与原子谬误

- **生态谬误**：用高层聚合数据推断低层个体；
- **原子谬误**：用低层个体数据推断高层单位。

共同点是**结论的层次与数据的层次不一致**。注意：即使结论碰巧为真，推理仍然无效——错的不是结论，是推理。

**判据：写下结论的主语（国家、城市、学校、个人），再写下数据的观察单位；两者不一致就必须补做该层次的资料，或把结论改写到数据支持的层次。**

**操作建议**：变量表增加一列"观察层次"；模型选择时优先考虑多层模型，而不是把宏观变量拆到个体上。

## 11. 十二条判据速记

1. 总体要界定单位、时间、空间、纳排四项。
2. 覆盖误差在抽样之前就存在；未覆盖率小 ≠ 偏误小。
3. 概率抽样五种，各有代价；判据是"有没有完整名单、层信息可靠否、群内同质否"。
4. 非概率抽样能支持机制，不能支持比例。
5. 样本量翻四倍才把区间减半；总体规模影响很小。
6. 样本量影响精度，不修复代表性。
7. 误差是单个统计量的属性，不是整份调查的属性。
8. 应答率是风险指示器，不是质量证明；看"应答倾向与 y 的相关"。
9. 单位无应答用加权，项目无应答用插补；两类分别报率。
10. 加权四来源相乘；权重变异系数大于 3 要截尾。
11. 统计概化靠概率，理论概化靠饱和；两套标准不能互评。
12. 结论主语与数据的观察单位必须同层。
