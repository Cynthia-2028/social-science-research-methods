## 2. 精读方法（可复现）

1. **抽文本**：整本转为纯文本，按 PDF 页插入 `[[p.N]]` 标记，便于定位。
2. **读结构**：每份材料先读开头部分确定版本与目录，据此判断它独有哪几章。
3. **按主题检索**：针对六个主题域设定关键词（如 frame / nonresponse / collider / functional form / process tracing / necessary condition 等），检索命中后读取上下文 80–200 行。
4. **交叉配对**：同一主题至少由两份材料支撑，冲突处单独记录。
5. **落成笔记**：四组笔记合计约 4.4 万字，含 300 余处页码锚点。

**因此本知识库的覆盖特征是：主题覆盖完整、篇幅覆盖有限。** 它适合用来判断"某个做法在什么条件下成立"，不适合用来替代对任一材料的系统阅读。

## 4. 明确未覆盖的部分

以下内容在材料中存在，但**本知识库未系统撰写**，因为它超出六个主题域或未实读：

- 深度学习与神经网络的具体结构；
- 生存分析与事件史模型的技术细节；
- 贝叶斯推断与先验设定；
- 时间序列与面板的高级设定（如动态面板、合成控制）；
- 多层模型的估计细节（本库只在"层次错配"处提及）；
- 文本分析与主题建模的具体算法（属另一条知识线）；
- 定性比较分析（QCA）的软件操作；
- 各国伦理审查制度的具体条款。

**若用户问题落在这些范围内，应明说"本知识库未系统覆盖"，并给一般性判断，不要假装有依据。**

## 5. 需要回查的清单

以下判断在笔记层面成立，但若要写入正式论文，建议回到原始材料核对上下文：

1. **应答率与偏误关系**的经验证据（59 项研究、959 个估计的汇总），引用前须核对汇总口径与适用条件。
2. **设计效应 13.43 与"3000 人等价于 223 人"** 的具体案例背景，属某一特定调查的估计，不可当作通则。
3. **功效 21%、复现率 36%** 等领域性数字，来自特定领域的元研究，不宜泛化到所有社会科学。
4. **PPV 7.8% 与 12.5%** 两个算例的基率与敏感度、特异度设定，属示例而非实测。
5. **"控制中介后模拟值从 −0.001 变到 −0.201"** 属特定数据生成过程下的模拟结果，方向可迁移，量级不可。
6. **"总体 78% vs 83%，分层 +6 / +4"** 的经典数值例，用于说明 Simpson 型反转，数值本身来自特定医学数据。
7. **"加入相关变量后标准误放大 12 倍、p 从 <0.0001 到 0.701"** 属某教材示例，量级仅供直觉。
8. **四类内部效度交互、十二类威胁清单** 属分类体系，不同材料粒度不同，写作时应说明采用哪一套。
9. **"某领域已发表研究功效中位数 21%"** 须核对领域与年份。
10. **各材料对"p 值门槛"的态度不一致**（有的主张保留刚性门槛，有的主张废弃），本库采取"确证性保留、探索性标注"的折中，属编辑判断而非材料共识。

## 6. 已主动修正的流传错误

在整理过程中发现并纠正了以下常见误传（本知识库不采用错误版本）：

| 流传说法 | 实际情况 |
|---|---|
| "95% 置信区间表示参数落在此区间的概率是 95%" | 概率属于构造程序，不属于具体区间 |
| "应答率低于 50% 数据不可用" | 率只是风险指示器；须看应答倾向与目标变量的相关 |
| "控制越多越严谨" | 可能引入对撞、中介、工具，反而制造偏误 |
| "处理前变量都可安全控制" | 前处理变量也可能是对撞（M 型结构） |
| "p 值越小效应越大" | p 受效应量与样本量共同影响 |
| "R² 高说明模型设定正确" | R² 与识别无关；混组拟合也能给出高 R² |
| "箱线图的两条须是最小值与最大值" | 标准做法是延伸到 1.5×IQR 内最远的观测 |
| "求异法能证明因果" | 逻辑条件在社会科学中几乎不可满足 |
| "案例研究因为样本小所以弱" | 案例的强项是机制可见与概念校准 |
| "混合方法一定更全面" | 无整合与元推断就只是两份研究 |
| "大数据可以不要抽样" | 无覆盖论证时推断强度低于概率抽样 |
| "AUC 高说明模型可用" | 与阈值表现无关；须报混淆矩阵并与基线比较 |

## 7. 使用边界

- 本知识库提供**判断框架与操作判据**，不提供具体数据、具体文献引用、具体软件代码。
- 所有"判据"均为**可操作的经验规则**，不是定律；遇到反例应优先相信反例。
- 涉及具体学科惯例（如某期刊的方法要求）时，以该领域最新规范为准。
- **查不到就明说查不到**：本库标注为"未系统覆盖"的领域，不应编造依据。
