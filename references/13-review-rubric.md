# 13 · 研究设计质量评审量表

**使用方式**：先判路线（看它声称的结论类型，不看它用了什么方法），再按对应权重打分。**六个维度分开给分，不给一个笼统总评。**

---

## 1. 六维分值表（基准权重）

| 维度 | 分值 | 评什么 |
|---|---|---|
| A. 问题与设计的匹配 | 20 | 结论级别与设计是否相称；措辞是否越级 |
| B. 概念与测量 | 20 | 概念是否分维；指标是否覆盖；信度效度证据 |
| C. 数据与抽样 | 20 | 框、覆盖、样本量、应答、加权、层次一致 |
| D. 推断策略 | 25 | 识别假设论证（或描述/机制推理链）；替代解释处理 |
| E. 透明度与可复现 | 10 | 十项最小信息；脚本与数据可得性 |
| F. 伦理与结论边界 | 5 | 知情与匿名；限制是否具体；是否写明"不能支持什么" |

**总分 = 六项之和（满分 100）。**

### 分路线权重调整

| 路线 | 调整 | 理由 |
|---|---|---|
| ① 描述与总体 | C 提到 28；D 降到 17 | 描述的可信度主要在框与应答 |
| ② 因果识别 | D 提到 32；C 降到 15 | 识别的分量最重，抽样可借力既有数据 |
| ③ 关联与建模 | D 与 B 各提到 25 / 22；C 降到 15 | 测量与设定比抽样更关键 |
| ④ 机制与过程 | D 提到 30；C 降到 12（改为"案例选择"） | 案例不以代表性论优劣 |
| ⑤ 概念与测量 | B 提到 32；C 降到 10 | 概念不清则一切无效 |
| ⑥ 新型数据与预测 | C 与 D 各提到 24 / 28；B 降到 16 | 生成机制与测试集是命门 |

## 2. 逐维评分标准

### A. 问题与设计的匹配（20）

| 档 | 描述 | 分 |
|---|---|---|
| 优 | 问句明确、结论级别清晰；设计与级别完全相称；贡献（推翻什么）写得出 | 18–20 |
| 良 | 问句清楚，级别基本相称；个别措辞略越级 | 14–17 |
| 中 | 问句偏宽，级别模糊；设计与级别部分错配 | 9–13 |
| 差 | 用 A 类设计回答 B 类问题；贡献说不出 | 0–8 |

**扣分点**：横断面谈过程（−6）；便利样本推总体（−6）；回归系数直接写"政策效果"（−5）；贡献只说"填补空白"（−3）。

### B. 概念与测量（20）

| 档 | 描述 | 分 |
|---|---|---|
| 优 | 概念分维且各有边界；每个维度有指标；有至少一项效度证据；做过等值性检验 | 18–20 |
| 良 | 分维清楚、指标覆盖基本完整；效度证据单薄 | 14–17 |
| 中 | 只有一句定义；指标只覆盖部分维度；无信效度检验 | 9–13 |
| 差 | 概念与指标明显错位（用代理变量直接替代构念） | 0–8 |

**扣分点**：单题测多维概念（−6）；用"被记录"测"发生"（−8）；指标与维度错位（−5）；跨群体比较未做等值性（−4）；无任何信度报告（−3）。

### C. 数据与抽样（20）

| 档 | 描述 | 分 |
|---|---|---|
| 优 | 总体四维界定；框覆盖率有估；应答率含分母定义；权重来源与变异有报；层次一致 | 18–20 |
| 良 | 多数具备，缺一两项（如未报设计效应） | 14–17 |
| 中 | 只报样本量与来源；框与应答情况模糊 | 9–13 |
| 差 | 样本来源不明；或明确便利样本却推总体 | 0–8 |

**扣分点**：只报 n 不报应答率（−4）；聚类样本无设计效应（−5）；加权方案未说明（−4）；结论主语与观察单位不同层（−6）。

### D. 推断策略（25）

| 档 | 描述 | 分 |
|---|---|---|
| 优 | 识别假设逐条写出并各自论证；替代解释≥3 且逐一处理；有针对性的稳健性检验 | 22–25 |
| 良 | 假设写出但论证单薄；替代解释处理了 2 个 | 17–21 |
| 中 | 只写"控制了变量"；替代解释缺；稳健性检验无关痛痒 | 10–16 |
| 差 | 无识别论证；或把相关直接写成因果 | 0–9 |

**扣分点**：只说"控制了重要变量"（−8）；控制中介后仍称总效应（−5）；控制对撞（−6）；系数随控制持续下降却停在显著处（−5）；无稳健性检验（−6）；多重比较未处理（−4）。

### E. 透明度与可复现（10）

| 档 | 描述 | 分 |
|---|---|---|
| 优 | 十项最小信息齐备；脚本/数据可得；随机过程可复现 | 9–10 |
| 良 | 缺一两项（如软件版本、参照组） | 7–8 |
| 中 | 缺三到五项；关键设定不明 | 4–6 |
| 差 | 无法判断做了什么 | 0–3 |

### F. 伦理与结论边界（5）

| 档 | 描述 | 分 |
|---|---|---|
| 优 | 知情与匿名交代清楚；限制具体到"哪条假设在什么情形失效"；明确写"不能支持什么" | 5 |
| 良 | 有限制讨论但较笼统 | 3–4 |
| 中 | 只有一句"存在局限" | 2 |
| 差 | 无 | 0–1 |

## 3. 三级判定（比总分更重要）

| 级别 | 含义 | 典型特征 | 处置 |
|---|---|---|---|
| **致命** | 结论不成立 | 设计无法回答该问题；识别假设明显违背；测量与构念错位；结论超出数据层次 | 必须重做或改结论 |
| **重要** | 结论削弱但可能仍成立 | 替代解释未充分排除；稳健性不足；样本偏误方向未知；关键变量测量粗糙 | 补检验或加限定 |
| **可改进** | 规范问题 | 报告不全、表格不规范、措辞越级、局限套话 | 修改即可 |

**判据：致命的判据是"若审稿人接受这条批评，文章的结论就必须撤回"。** 只需"加一句限制"就能保住的，是重要，不是致命。

---

## 4. 常见"看起来像优点其实不是"的表述

| 表述 | 为什么不算优点 |
|---|---|
| "样本量达十万" | 不修复框偏差与无应答偏差 |
| "控制了二十个变量" | 可能引入对撞、中介、工具，反而制造偏误 |
| "R² 达 0.6，模型拟合良好" | 与识别无关；可能是混组拟合 |
| "p<0.001，高度显著" | 只说明标准误小；效应可能微不足道 |
| "用了机器学习，方法先进" | 预测力不等于解释力；可能是黑箱或过拟合 |
| "做了混合方法，证据更全面" | 若无整合与元推断，只是两份研究 |
| "案例典型，具有代表性" | 案例的辩护词应是机制可见，不是代表性 |
| "结果稳健（换了几种标准误）" | 换标准误只测方差，不测混杂 |

## 5. 评审输出模板

```
【路线判定】该文声称的结论级别为 ___（描述/关联/因果/机制/概念/预测），与所用设计 ___（相称 / 部分错配 / 明显错配）。

【六维评分】
A 问题与设计匹配：__/20
B 概念与测量：__/20
C 数据与抽样：__/20
D 推断策略：__/25
E 透明度与可复现：__/10
F 伦理与结论边界：__/5
合计：__/100

【三级判定】致命 __ 项 / 重要 __ 项 / 可改进 __ 项

【逐条问题】
1. [环节] 问题描述 → 为什么是问题 → 怎么改（具体到补什么检验、改哪句话）

【最值得肯定的一处】
（一处即可，必须具体，不要客套）
```

---

## 6. 评分纪律（防止评审失真）

1. **不因写作漂亮加分，不因选题热门加分。** 只评证据与推理。
2. **不给"印象分"。** 每一分都要能指向一个具体环节。
3. **扣分必须给改法**，否则该扣分不成立（你只是不喜欢，不是它错）。
4. **同类问题合并计数**，不要把一个问题拆成五条来压分。
5. **先评"它想做的事做到了没有"，再评"它想做的事值不值得做"。** 两件事分开说，不要混成一句"质量不高"。
6. **不用另一条路线的标准打分。** "样本不随机"不是对案例研究的有效批评。
