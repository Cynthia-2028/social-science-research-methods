# 01 · 方法知识地图

这份文件是"导航图"：告诉你社会科学研究方法由哪些层构成、每一层解决什么问题、学的时候按什么顺序走。

---

## 1. 四层结构：为什么很多争论其实不在同一层

方法学里的争吵，一半是层次混淆。把层次分清，很多"对立"会自动消解。

| 层 | 回答什么 | 典型内容 | 争错了会怎样 |
|---|---|---|---|
| **L1 本体论层** | 社会世界由什么构成：类别是"发现"的还是"建构"的 | 实在论 / 唯名论；社会类别的存在方式 | 把建构性类别当自然类别，跨群体比较失真 |
| **L2 逻辑层** | 什么样的推理算"支持" | 演绎 / 归纳 / 溯因；必要与充分条件；反事实 | 用归纳证据做演绎宣称；把"没被证伪"当"被证明" |
| **L3 设计层** | 用什么比较结构产生证据 | 抽样、测量、实验/准实验/案例/比较、混合 | 问题与设计错配，后面全错 |
| **L4 技术层** | 用什么统计或分析工具 | 回归、检验、模型、编码、文本分析 | 技术正确但回答的不是原问题 |

**使用规则**：先定 L1 承诺 → 再定 L2 推理形式 → 再定 L3 设计 → 最后才选 L4 技术。**倒着来的设计，通常会返工。**

## 2. 全流程链：从现象到结论的九步

```
现象 ──①问题化──▶ 研究问题 ──②概念化──▶ 构念与维度 ──③操作化──▶ 指标
  │                                                              │
  └──⑨写作与边界◀──⑧推断与措辞◀──⑦分析◀──⑥设计◀──⑤抽样◀──④测量工具
```

| 步 | 核心动作 | 最容易崩的地方 | 去哪查 |
|---|---|---|---|
| ① 问题化 | 把现象变成可回答的问句，并定结论类型 | 问句太大、动词越级 | `02-question-to-design.md` |
| ② 概念化 | 指定维度与每个维度的边界 | 只写一句定义就往下走 | `03-concepts-and-measurement.md` §2 |
| ③ 操作化 | 每个维度至少一个可复现指标 | 指标与维度错位、只覆盖一个维度 | `03-concepts-and-measurement.md` §3 |
| ④ 测量工具 | 题项、编码规则、预试 | 双重问题、引导性、回忆困难 | `03-concepts-and-measurement.md` §7 |
| ⑤ 抽样 | 框、抽样方法、样本量、应答 | 框不全、只报样本量不报覆盖率 | `04-sampling-generalization.md` |
| ⑥ 设计 | 比较结构（组、时点、处理） | 画不出比较结构图 | `02-question-to-design.md` §2 |
| ⑦ 分析 | 模型或编码，含诊断 | 函数形式错、忽略设计效应 | `06-modeling-and-diagnostics.md` |
| ⑧ 推断 | 假设、区间、替代解释 | 把关联写成因果、把不显著写成无效应 | `07-inference-and-uncertainty.md` |
| ⑨ 写作 | 七件套 + 边界声明 | 局限写成套话 | `12-writing-the-design.md` |

## 3. 六条路线的最小概念集

学一条路线，先掌握这五个概念；其余都是它们的组合。

**① 描述与总体**：总体与抽样框 / 入样概率 / 设计效应 / 无应答 / 加权
→ 一句话：**描述的可信度取决于"谁不在样本里"，而不是"样本有多大"。**

**② 因果识别**：潜在结果 / 可交换性 / 混杂 / 正定性 / 识别策略
→ 一句话：**因果不是算出来的，是设计出来的；所有因果估计都在用一个不可检验的假设换另一个。**

**③ 关联与建模**：偏效应 / 函数形式 / 交互 / 共线性 / 影响力点
→ 一句话：**系数本身没有含义，含义来自"你在估什么"与"模型设定对不对"。**

**④ 机制与过程**：机制 / 过程追踪 / 反例 / 必要与充分条件 / 案例选择
→ 一句话：**机制研究的目标是让过程可见，不是让样本变大。**

**⑤ 概念与测量**：构念 / 维度 / 指标 / 信度 / 效度
→ 一句话：**测量不是给对象贴数字，而是约定一套可复现的操作；约定只保证可重复，不保证指得准。**

**⑥ 新型数据与预测**：生成机制 / 覆盖 / 构念效度 / 测试集 / 基率
→ 一句话：**数据量大不等于推断更硬；先问"谁生成了这条记录、谁没被记录"。**

## 4. 学习路径：三条，按目的选

**路径甲：为了做研究（推荐）**
按全流程九步走一遍，用**自己的一个真实题目**当练习材料。每步产出一样东西：问题句、维度表、指标表、抽样说明、比较结构图、模型或编码方案、假设清单、边界声明。走完一轮，比读三本教材有用。
配套：`02` → `03` → `04` → `05` 或 `08` → `06` → `07` → `12`。

**路径乙：为了评审别人的研究**
不按流程走，按"找缺口"走。拿到一篇论文，依次问：
1. 它的结论是哪一级（描述/关联/因果/机制）？
2. 它声称的级别与设计是否匹配？
3. 它的三条关键假设是什么，哪条最脆弱？
4. 它有没有报告"反面证据"（系数轨迹、安慰剂检验、反例、未应答对比）？
配套：`13-review-rubric.md` + `02` §6 的错配清单。

**路径丙：为了应试或系统补课**
按"概念对"学，不按章节学。每对概念准备三样：区分判据、一个例子、一个常见误读。核心概念对清单：
信度/效度 · 内部/外部效度 · 抽样误差/非抽样误差 · 混杂/中介/对撞 · 总效应/直接效应 · 一致/充分 · 描述/解释 · 归纳/演绎 · 横断面/纵贯 · 概率/非概率抽样 · 指数/量表 · 类型/连续 · 显著性/效应量 · 预测/解释。

## 5. 五种研究传统的对照（选传统等于选"什么算好研究"）

| | 定量—调查传统 | 实验—因果传统 | 案例—比较传统 | 诠释—质性传统 | 计算—预测传统 |
|---|---|---|---|---|---|
| 好研究的标准 | 样本代表、测量有效、模型正确 | 识别可信、假设明确、稳健 | 机制清晰、案例选择有理由、能处理反例 | 意义还原、反身性、厚描述 | 预测准确、可复现、构念不被污染 |
| 核心弱点 | 因果弱 | 外部效度弱 | 不能给比例 | 不能给效应 | 解释力弱 |
| 常见误用 | 把相关当因果 | 把实验室结论当社会规律 | 用"代表性"为案例辩护 | 用个案断言普遍 | 用预测结果做因果建议 |

**关键提醒**：这五套标准**不能互相打分**。"你的样本不随机"不是对案例研究的有效批评；"你没有机制"不是对描述性调查的有效批评。批评必须用对方传统的标准。

## 6. 二十四道自测题（能答出判据才算会）

**描述与抽样**
1. 你的抽样框覆盖了谁、漏了谁？覆盖率怎么估？
2. 应答率 40% 能不能说明数据不可用？判据是什么？
3. 样本量翻四倍，置信区间缩小多少？
4. 为什么要报告设计效应？不报会怎样？

**测量**
5. 一个概念有三个维度，你的指标覆盖了几个？
6. 信度低与效度低，补救方法有什么不同？
7. "1、2、3"是标签、名次还是刻度？这决定了什么？
8. 一个人按你写的操作定义重做，能得到同一份数据吗？

**因果**
9. 一致性要求"处理说得清"，怎么算说得清？
10. 可交换性能被检验吗？不能的话要做什么？
11. 正定性问题在数据上长什么样？
12. 双重差分要相信什么？平行的版本是加性还是乘性？
13. 工具变量三个条件里，哪个能被数据检验？
14. 断点回归给出的是谁的效应？

**关联与建模**
15. 同一个回归系数，三种解读分别需要什么前提？
16. 控制中介之后，系数变成了什么？
17. 控制对撞为什么会"凭空造出关联"？
18. 共线性损害的是无偏性还是精度？

**推断**
19. p=0.03 能说"零假设为真的概率是 3%"吗？
20. 样本量增大后，原本不显著的结果变显著，说明了什么？
21. 做了 50 次检验，要把族错误率控制在 5%，单次门槛约多少？

**机制与新数据**
22. 案例研究的强项是什么，弱项是什么？用什么为它辩护？
23. 必要条件的集合定义是什么？怎么检验？
24. 预测模型的 AUC 很高，为什么还可能是有害的？

> 参考答案散在各 reference 文件；答不出判据（只说得出名词）的，回到对应文件重读该节。

## 7. 一页速记

- 四层：本体论 → 逻辑 → 设计 → 技术。**顺序不能倒。**
- 九步：问题 → 概念 → 操作 → 工具 → 抽样 → 设计 → 分析 → 推断 → 写作。
- 六路线：描述 / 因果 / 关联 / 机制 / 概念 / 预测。
- 四级结论：描述 / 关联 / 因果 / 机制。**不能免费升级。**
- 三个永远要写的：识别假设、替代解释、结论边界。
- 一个永远要问的：**谁不在我的数据里。**
